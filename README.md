# Rookline Drive Releases

Public Windows installer releases for **Rookline Drive** — live telemetry and a VR HUD for Le Mans Ultimate.

This repository hosts installer downloads only. Product source code, ZIP packages and development artifacts remain private.

## Download

[Download the Drive 0.6.29 VR test installer](https://github.com/convexrook2/Rookline-Drive-Releases/releases/download/v0.6.29/Rookline-Drive-Setup.exe)

Drive 0.6.29 is a **pre-release VR test candidate**, pending the latest headset and installed-upgrade acceptance. It adds optional Windows/minimized startup and verified manual installer updates. Your saved HUD layout and settings are preserved.

See [Releases](https://github.com/convexrook2/Rookline-Drive-Releases/releases) for release notes and available installers.

Windows x64. The installer includes the .NET runtime; WebView2 and SteamVR are required for VR mode. The installer is unsigned.
