# Rookline Drive Releases

Public Windows installer releases for **Rookline Drive** — live telemetry and a VR HUD for Le Mans Ultimate.

This repository hosts installer downloads only. Product source code, ZIP packages and development artifacts remain private.

## Download

[Download the Drive 0.6.30 VR test installer](https://github.com/convexrook2/Rookline-Drive-Releases/releases/download/v0.6.30/Rookline-Drive-Setup.exe)

Drive 0.6.30 is a **pre-release VR test candidate** with eight configurable HUD views, Previous/Next cycling and locked first-use panel defaults. Existing saved HUD layouts and button assignments are preserved. In-game/headset acceptance remains pending.

Choose cycle membership and panel contents in **Settings → HUD views**, then click **Save views**. Optional Windows/minimized startup and verified manual updates remain available.

See [Releases](https://github.com/convexrook2/Rookline-Drive-Releases/releases) for notes and earlier installers.

Windows x64. The installer includes the .NET runtime; WebView2 and SteamVR are required for VR mode. The installer is unsigned.
